# Состав приложения

`manifest.json` фиксирует порядок исходных единиц. Сборка объединяет их в один classic script внутри HTML; так сохраняются существующие синхронные команды, undo/redo и экспорт одного автономного файла. Это явная композиция с общим лексическим контекстом, а не независимые ES modules или новая архитектура с импортами. Исходные единицы и styles/ не публикуются отдельно: сайт содержит только собранный HTML и действующие независимые app/cloud-модули.

| Единица | Ответственность и граница |
| --- | --- |
| write-guard.js | Единственная власть межвкладочной записи. Получает LockManager/key/portable, не читает DOM и модель. |
| core.js | Модель состояния, DOM/text helpers, команды и восстановление истории. Использует общий формат и ограниченную историю. |
| board.js | Диапазоны, раскладка, карточки, жесты и перерисовка. Читает модель/вид; изменения проводит через change. |
| editors.js | Формы карточек, треков, релизов и удаления; перевод пользовательского ввода в команды. |
| exchange.js | Тема, импорт/экспорт JSON и автономного HTML. Пишет библиотеку только через writeVault. |
| controls.js | Ошибки форм, SVG и собственные select/клавиатура, без записи модели. |
| vault.js | Библиотека, активный проект, настройки вида и вкладки. writeVault проверяет владельца, старые байты и формат. |
| lifecycle.js | Контрольная точка PWA, публичный snapshot-мост облака, запуск и индикатор права записи. |

В `public/app/project-format.js` и `history.js` остаются независимые чистые модули со своими portable installer. Cloud/recovery/integrations не получают изменяемую ссылку на модель. В stylesheet порядок каскада сохранён; переопределения media/theme после базовых правил намеренны. Не удалять их как дубликаты без отдельного воспроизведения.

Изменять нужно исходную единицу, затем `npm start` или `npm run build`. Не править site/index.html. Новые единицы включать явно в manifest; build отклоняет имена с выходом из каталогов. Дальнейшая замена общего контекста на ES modules — отдельная архитектурная задача, не скрытая полная перепись текущего релиза.
