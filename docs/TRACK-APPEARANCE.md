# Треки и компактная мобильная таблица

В редакторе трека выбираются иконка, цвет палитры или свой #RRGGBB. «Без иконки» и пустой цвет возвращают прежнее оформление. Иконки — собственные SVG с единым штрихом, без внешнего CDN; всего 41. Неизвестный будущий slug отображается папкой. Иконка, цвет и полное название сохраняются в JSON, автономном HTML и синхронизации; изменение проходит через отмену/повтор. Палитра трека не заменяет статусы карточек.

Меню → «Компактные заголовки»: на телефоне режим включён по умолчанию для ещё не настроенного проекта. В нём скрыты счётчики и описания треков, названия релизов занимают одну строку; длинный комментарий можно раскрыть отдельно. Название трека закрепляется внутри своей строки при прокрутке, а верхняя часть таблицы остаётся закреплённой. Выбор режима хранится отдельно для каждого проекта и переживает перезапуск web/PWA. Внешний вид проекта не меняется на других устройствах от переключения этого режима.

API 1.1: track create/update принимает `icon` и `color`, null очищает поле; ожидаемая ревизия обязательна. `roadmap_capabilities` сообщает фактическую версию сервера. `api/capabilities.json` содержит весь каталог с русскими названиями и SVG paths, без данных аккаунта. В рабочем Supabase klsxfhettffjbnmuxivg 09.11.2026 применена миграция `track_project_appearance_api_v1_1` из `server/track-appearance-update.sql` по явному разрешению владельца. Ручных SQL-действий от пользователей/агентов больше не требуется.

Плагин 0.2.0 добавляет проверку и обновление управляемых файлов с SHA-256. Серверные дополнения в совместимом API обнаруживаются без обновления локального кода; для новых локальных инструментов применяется обновление и перезапуск MCP, без повторной настройки credentials. Старый 0.1.0 обновляется проверяемым bootstrap `update.mjs` из официального manifest — переустановка в клиенте не обязательна. Автоматических фоновых обновлений и чтения Logs Query нет.

Цвет вкладки проекта хранится в `project.color` (#RRGGBB). API: `roadmap_integration_project(p_project_id,p_expected,p_patch)` / инструмент `roadmap_project_update` / CLI `update-project --file FIELDS.json --expected REV`. Патч принимает name/description/color; null очищает цвет, остальные поля сохраняются. API использует прежнюю проверку токена write и ревизии. В настройках проекта доступны палитра и HEX; цвет переносится между устройствами вместе с проектом.
