# Компактная доска и управление проектами

Проверено локально 27.10.2026 в изолированном Google Chrome, ширины 320, 390 и 1280 CSS px. Физический телефон не проверялся.

- При 390 px ширина колонки релиза уменьшена с 224 до 128 px; пустые строки — со 100 до примерно 70 px; карточка с диапазоном — примерно с 84 до 54 px по высоте. Высота растёт по содержимому.
- Две колонки релизов видны одновременно; прокрутка ограничена доской. Кнопки трека не перекрывают счётчик.
- Редактирование карточки, сокращение диапазона клавиатурой, отмена и скрытие/возврат трека работают.
- Отмена удаления сохраняет проект; удаление последнего открывает пустой проект. Кнопка «Восстановить» возвращает удалённый проект и его карточки, пока сообщение доступно.
- Отмена импорта сохраняет хранилище; новый импорт добавляет вкладку. Обновление совпавшего по названию проекта не создаёт дубликат и поддерживает отмену/повтор.
- Можно явно создать одноимённую копию. При нескольких совпадениях собственное меню позволяет выбрать проект для обновления.
- Перезагрузка сохраняет импорт, обновление и удаление. Неподдерживаемая версия JSON отвергается без изменения хранилища.
- Ошибок JavaScript в проверенных сценариях нет. `npm run build` и `git diff --check` завершились успешно.
