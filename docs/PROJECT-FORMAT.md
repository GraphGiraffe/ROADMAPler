# Переносимый проект · версия 1

Расширение: `.roadmap.json`. UTF-8, один проект в файле. Пример с реальными данными — `projects/playroom.roadmap.json`, вне публикуемой папки сайта.

```json
{
  "format": "roadmap-project",
  "formatVersion": 1,
  "schema": 2,
  "project": {"id": "example", "name": "Пример", "description": "", "updatedAt": "2026-10-27"},
  "tracks": [{"id": "product", "title": "Продукт", "subtitle": ""}],
  "releases": [],
  "tasks": [],
  "sources": []
}
```

`schema: 2` унаследовано от прототипа доски. Версия переносимого файла задаётся `formatVersion`; будущая миграция не должна угадывать её по приложению.

Карточка содержит `id`, `track`, `release`, `title`, `description`, `status`, `accept`, `source` и необязательный `comment`. Релиз задаётся ID из `releases`, либо строкой `backlog`. Статусы: `idea` (идея), `check` (нужно проверить), `planned` (запланировано), `work` (в работе), `done` (выполнено), `blocked` (заблокировано), `paused` (на паузе). Перенос в другой релиз не меняет статус. Неизвестный статус отвергается до изменения проекта; ранние версии приложения могут отвергать новые статусы `blocked`/`paused`.

Трек: `id/title/subtitle`. Релиз: `id/title/note/locked`. Источник: `id/title/path`. Путь источника — текстовая ссылка на происхождение идеи; импорт не читает локальные файлы по этому пути.

Порядок массивов сейчас определяет порядок треков, релизов и карточек. Backlog не является записью релиза, всегда отображается справа. Ссылки карточек должны указывать на существующие треки/релизы, ID должны быть уникальны в своих коллекциях.

Приложение проверяет тип файла, версию, основные списки, ID и связи карточек. Для полноценного приложения нужны полная схема, лимиты размера/строк, проверка всех вложенных полей и импорт с выбором политики конфликтов. Текущий импорт заменяет только активный проект с возможностью отмены; другие вкладки проектов сохраняются. Слияние и экспорт всей библиотеки пока не реализованы.

Локальная библиотека хранится отдельно от переносимого проекта: оболочка `{version: 1, active, projects: [{id, data}]}`. `id` записи библиотеки определяет вкладку, а `data` содержит переносимый проект без потери дополнительных полей. Версия библиотеки не является `formatVersion` импортируемого файла.
