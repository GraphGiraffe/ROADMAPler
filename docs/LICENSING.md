## Принятый компромисс

PolyForm Noncommercial разрешает использование, изменение и распространение
кода для допустимых целей, определённых её стандартным текстом. Там также
прямо перечислены допустимые личные применения и категории организаций.
Она не запрещает коммерческое использование безоговорочно для любого случая.

**PolyForm Noncommercial не обязывает публиковать исходники чужих доработок.**
Наличие исходников этого репозитория и разрешение изменять код не создают
такой обязанности для производных версий. Дополнительного copyleft-условия
к стандартной лицензии проект не добавляет.

CC BY-NC-SA требует авторства, некоммерческого использования и тех же условий
для распространяемых переработок соответствующих материалов. Она применяется
к документации и отдельным художественным материалам, а не подменяет лицензию
программного кода.

Этот набор относится к source-available: он не заявляется как Open Source
в смысле OSI с разрешённым коммерческим использованием для любой цели.

## Возможность коммерческого выпуска владельцем

GraphGiraffe может отдельно разрешать коммерческое использование материалов,
на которые владеет нужными правами. Получать разрешение пользователей
публичной некоммерческой версии для этого не требуется.

Для чужих вкладов нужны соответствующие права: они не переходят к владельцу
проекта автоматически. Порядок описан в [CONTRIBUTING](../CONTRIBUTING.md).
Лицензии сторонних компонентов должны также допускать будущий сценарий.
