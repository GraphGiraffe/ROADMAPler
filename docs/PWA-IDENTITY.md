# Идентификатор установки PWA

Стабильный manifest ID: `/roadmapler`. Он вычисляется относительно origin start_url. Значение `./` здесь ошибочно: оно превращается в корень домена и конфликтует с соседними PWA, даже если их scope и кеши разделены. start_url и scope остаются `./`.

Это изменение установочной идентичности. Старую конфликтующую Linux-установку может понадобиться удалить и установить заново; не удалять данные сайта и пользовательские проекты/альбомы. Уже установленные Android-приложения не требуют массовой очистки: их обновление/миграция проверяются отдельно.

### Тема при запуске

Тема из `roadmap-theme` применяется в `head` до загрузки основного кода; при отсутствии сохранённого значения используется тема автономного HTML или системная тема. Цвет `theme-color` берётся из действующей CSS-палитры.

Для тёмной темы сборка создаёт `manifest-dark.webmanifest` из основного манифеста: изменяются только `background_color` и `theme_color`. ID, scope, стартовый URL и иконки совпадают, поэтому это варианты оформления одной установки. Оба манифеста входят в офлайн-оболочку. При переключении темы меняется ссылка на манифест.

Системную заставку с иконкой рисует Chrome до выполнения JavaScript. Уже установленная PWA может показывать прежний фон, пока Chrome не обновит метаданные установки; немедленная смена не гарантируется. Не нужно удалять приложение или очищать данные ради обновления заставки. Цвет страницы и системной строки после открытия обновляется сразу.
