# Выполненные и сжатые релизы

Проверено 27.10.2026, локальная сборка `site/`, изолированный Google Chrome, экран 390 × 844 CSS px.

- Настройка «Выполненные релизы» включена по умолчанию. Снятая галочка удаляет колонки из отображаемой сетки целиком, без сжатого остатка. Данные проекта не удаляются.
- Убирается только релиз с `defaultStatus: done`, если все карточки, включая покрывающие его диапазоном, имеют статус `done`. Пустой релиз с этим правилом тоже считается выполненным. Backlog не исключается.
- Релиз с другим правилом остаётся даже при выполненности всех карточек. Любая незавершённая карточка сохраняет колонку. Поиск, фильтр трека и видимость выполненных карточек не меняют критерий.
- Ручное сжатие независимо от этой настройки. Сжатый заголовок сохраняет цвет и знак статуса, узкая колонка — соответствующий фон. Повторное включение настройки возвращает прежнее сжатие.
- Карточка с диапазоном сохраняется в видимых колонках, даже если начальный релиз исключён. Перетягивание границы и отмена проверены с такой скрытой начальной колонкой.
- Настройка сохраняется локально, переносится через снимок PWA-обновления и в экспортируемый автономный HTML.
- Файл `projects/ROADMAPler.roadmap.json` действительно импортирован: семь релизов, 36 карточек, шесть треков. Отключение выполненных релизов убирает все семь исторических колонок.
- `npm run build`, `git diff --check` и перечисленные проверки Chrome завершились успешно. Физический телефон не проверялся.
