# Проверка PWA и интерфейса

Локальная проверка 27.10.2026. Сервер отдавал собранный `site/` под `/ROADMAPler/`; использован изолированный headless Google Chrome. Тесты не добавлялись в GitHub Actions.

- `npm run build` — успешно; JavaScript проверен `node --check`.
- Создание карточки в выбранной ячейке, добавление релиза и трека, переименование, скрытие/возврат строк и колонок — проверено в браузере.
- Вкладки проектов: разделение данных, переключение, переименование и восстановление после перезагрузки — проверено.
- Ширины 320, 390, 768 и 1440 px: страница не расширяется за экран; доска прокручивается внутри рабочей области.
- Семь пунктов статуса с цветами и SVG-иконками; выбор блокировки и паузы, назначение релиза, управление меню клавиатурой — проверено.
- Ошибки обязательных полей показываются внутри формы. Системные `alert`, `confirm`, `prompt` не используются.
- Офлайн-перезагрузка после установки Service Worker: оболочка и локальные проекты доступны.
- Подмена ревизии на изолированном сервере вызвала ожидание нового worker. Обновление применялось по кнопке, сохраняло проект и историю отмены.
- Открытая форма и ошибка хранилища блокировали обновление. Другая вкладка не перезагружалась; посторонний кеш не удалялся.
- Экспортированный HTML открывался через `file://` с карточками и работающими собственными меню, без дублирования элементов и PWA-зависимостей.

Установка на физический телефон и особенности меню конкретного мобильного браузера этой проверкой не подтверждены. Данные проектов пока используют квоту `localStorage`; резервная копия создаётся экспортом пользователя.
