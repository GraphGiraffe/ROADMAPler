# ROADMAPler · облачный прототип · 27.10.2026

Первый выпуск облачной синхронизации. Основной режим использует Supabase владельца; личный приватный GitHub-репозиторий доступен как альтернативное подключение. Локальная работа не требует аккаунта.

## Что добавлено

- Вход и регистрация обычного аккаунта через Supabase; подключён проект владельца.
- Подключение личного GitHub с токеном и необязательным шифрованием проектов перед отправкой.
- Выбор локального или облачного режима отдельно для каждого проекта. Подключение аккаунта не отправляет локальные проекты автоматически.
- Локальное сохранение изменений без сети и продолжение обмена после восстановления связи.
- Проверка версий, конфликты двух устройств, сохранение обеих копий и восстановление облачной версии.
- Очередь удаления и восстановление уже удалённого облачного проекта с сохранением привязки.
- Индикация соединения и ошибок, защита сеанса при обновлении PWA.
- Источники скрыты из интерфейса, но их метаданные сохраняются в переносимых файлах.

## Как начать

1. Обновить PWA через меню → «Проверить обновления» → «Обновить и продолжить».
2. Меню → «Аккаунт», выбрать ROADMAPler и войти или зарегистрироваться.
3. Открыть настройки выбранного проекта нажатием на активную вкладку → «Синхронизация…» → «Облачный».
4. На другом устройстве войти в тот же аккаунт: облачные проекты появятся в списке.

Для GitHub выбрать «Мой GitHub» и указать приватный репозиторий, ветку и ограниченный токен. При шифровании на другом устройстве требуется тот же отдельный ключ; он не сохраняется вместе с токеном.

## Границы прототипа

Реальная связь с Supabase из Chrome, CORS и запрет анонимного доступа к таблицам и функции записи проверены. Подтверждение почты включено. Встроенная почта Supabase имеет ограничения: для регистрации произвольных пользователей нужно настроить собственный SMTP либо заранее создать подтверждённые тестовые аккаунты в панели владельца.

Тестовые аккаунты для авторизованной проверки не предоставлены: вход, синхронизация двух устройств и изоляция пользователей на настоящем Supabase ещё не подтверждены. Эти сценарии проверены в Chrome с имитацией API, а серверные права и конкурентная запись — на отдельном PostgreSQL. Настоящий GitHub-токен и физический телефон тоже не проверялись. Восстановление пароля в интерфейсе пока отсутствует.

Это предварительный выпуск для испытаний. Перед использованием важных данных сохраняйте отдельный JSON/HTML-экспорт. Supabase этого прототипа размещён за пределами РФ; размещение в России остаётся возможным следующим этапом.

Подробности подключения и ограничений: [CLOUD-SYNC](../CLOUD-SYNC.md). Переносимые файлы не содержат токенов или привязок к облаку. Пользовательские проекты и архивы не входят в веб-сборку.

## Проверки выпуска

- `npm run build`, `node --check` облачных модулей, `git diff --check`.
- Chrome с имитацией GitHub API: два устройства, настоящее WebCrypto, офлайн-правки и перезапуск, конфликты, обе копии, версии, смена режима, очередь удаления и восстановление.
- Chrome с имитацией Supabase API: вход, проверка версии, разные аккаунты, обновление сеанса, снимок PWA и автономный HTML без учётных данных.
- PostgreSQL: RLS, запреты прямого доступа, CAS, ограниченная история, удаление и восстановление.
- Импорт/экспорт с сохранением скрытых метаданных источников; настоящее соединение браузера с настройками Supabase.
