# Проверка диапазонов и статусов колонок

Локально, 27.10.2026, собранный `site/` под `/ROADMAPler/`, изолированный Google Chrome.

- Диапазон отображается одной карточкой; задачи с пересекающимися релизами занимают разные строки.
- Правая граница меняется мышью, клавишами ←/→ и эмулированным touch-жестом. Начало и конец выбираются в диалоге карточки.
- Правила релиза и backlog выбираются собственным меню; цвет и SVG-иконка отображаются в заголовке.
- Реальный перенос мышью применяет статус колонки. Отмена/повтор восстанавливают одновременно положение, диапазон и статус. Перенос в backlog снимает диапазон.
- Удаление промежуточного релиза сохраняет карточки и сокращает диапазоны; отмена возвращает релиз и границы.
- Перезагрузка сохраняет диапазоны и правила. Неверный обратный диапазон отвергается без изменения проекта.
- Ширины 320, 390, 768 и 1440 px: горизонтальная прокрутка ограничена рабочей доской.
- Обновление Service Worker восстанавливает данные версии 2 и историю сеанса; последующий офлайн-запуск сохраняет проект.
- JSON-экспорт содержит `formatVersion: 2`, `releaseEnd`, правила колонок. Автономный HTML восстанавливает диапазоны, стили заголовков и собственные меню.
- Первая установка worker не показывает ложное уведомление об обновлении.

Выполнены `npm run build`, `node --check` и `git diff --check`. Физический мобильный браузер не проверялся; touch-проверка использовала Chrome DevTools Protocol.
